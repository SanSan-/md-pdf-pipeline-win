# Пакеты MiKTeX для Windows x64

Для сборки на новом компьютере установите Basic MiKTeX. Менеджер пакетов может заранее установить весь набор по списку идентификаторов. Для компьютера без доступа к сети подготовьте локальный репозиторий с архивами и служебными базами MiKTeX. Порядок загрузки, переноса и установки приведён в руководстве. [Список для менеджера пакетов](resources/miktex-packages.txt) · [Подготовка компьютера без доступа к сети](INSTALL-GUIDE.md#подготовка-компьютера-без-доступа-к-сети)

## Архивы по назначению

На чистой установке Basic MiKTeX 26.5 для Windows x64 уже присутствовали 33 из 69 пакетов. **Полужирным выделены 36 пакетов, которые потребовалось доустановить.** Все 36 установлены из локальных архивов, после чего LuaLaTeX собрал контрольный PDF с отключённой автоматической установкой.

## Состав набора

В наборе 69 архивов. За основу взяты файлы, которые LuaLaTeX открывает при сборке встроенного примера и книги о триангуляции многоугольника. Эти документы используют кириллицу, формулы, таблицы, код, перекрёстные ссылки и иллюстрации. Дополнительно учтены файлы создания формата LuaLaTeX, сам движок для Windows x64, команда `\cancel` для математических выражений и зачёркивание текста через `~~…~~`. Владельцы файлов определены по манифесту пакетов MiKTeX. Итоговый список учитывает объявленные зависимости пакетов.

Основная гарнитура DejaVu и математический шрифт Latin Modern Math входят в набор. MiKTeX создаёт файл формата, карты шрифтов и кеш LuaLaTeX при подготовке окружения. Системные шрифты Windows для дополнительных символов предоставляет операционная система.

В стабильном репозитории файлы подсистемы вывода LaTeX3 `l3backend-luatex.def` и `l3backend-luatex.lua` входят в `l3kernel`. В прежних поставках они находились в пакете `l3backend`. Файл `nameref.sty`, ранее входивший в `hyperref`, теперь поставляется отдельным пакетом `nameref`.
