# Начало работы

Проект собирает статьи Markdown в PDF. Для запуска на новом компьютере начните с [руководства по установке](../../INSTALL-GUIDE.md). Параметры команды, примеры и порядок передачи архива описаны в [руководстве пользователя](../../README.md).

Для изменения сборщика используйте [действующую спецификацию и её сценарии](../specs/markdown-pdf/spec.md). Иерархией и ссылками управляет [модуль сборки книги](../../book.py), иллюстрациями и кешем — [модуль изображений](../../images.py), вёрсткой и публикацией PDF — [конвейер сборки](../../pipeline.py).
